# exports／申請記錄匯出

- `index.html` — **網頁版比對表**，瀏覽器直接打開即看（帶狀態篩選、搜尋、列印友善），與 xlsx 同一份數據，由 `kindy_total/build_compare_html.py` 從 xlsx 渲染。
- `N班申請記錄比對_2026-10-09.xlsx` — N 班報名記錄與憑證比對表（更新時間 2026-10-09）。
  - Sheet 1「申請記錄比對」：模板欄位（學校／報名開放時間／申請編號／報名完成時間／面試／地址／網址）＋ 匹配狀態 ＋ 數據來源 ＋ 備註。
  - Sheet 2「說明」：比對規則、數據來源代碼（A=追蹤表HTML、B=模板截圖、C=N班申請.zip 憑證）。
- 比對規則摘要：已報名以 zip 內 PDF 憑證為準；模板與憑證不符標「信息不一致」；無憑證標「未報名」（細分尚未開放／已截止）。
- 已移除申請人姓名、出生日期等個人敏感資料。
